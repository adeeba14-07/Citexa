# Citexa repair notes

The repaired project preserves the existing workspace and adds account settings and saved-plan tables. After updating an existing database, run `pnpm run setup` once with the correct `DATABASE_URL` to apply the schema.

## Delivered

| Area | Change |
|---|---|
| YouTube intake | Canonicalizes watch, `youtu.be`, Shorts, Live, embed, mobile, music, and no-cookie URLs; rejects playlist-only/invalid IDs; reports actionable errors. Learners can select Auto, English, Hindi, Tamil, Telugu, Bengali, or Marathi captions. Auto mode prefers English, then supported Indian-language tracks. When captions are unavailable, the downloader prefers audio-only media, skips unnecessary video-frame analysis, and transcribes chunks with bounded concurrency to reduce processing time. |
| PDF/PPTX source viewer | Keeps the authenticated preview and original-file fallback. PDF citations now request a PyMuPDF-rendered page with an amber highlight where extracted citation text can be matched. Failed matches fall back to the ordinary page preview. If a stored PowerPoint slide image is missing but its original deck still exists, the server reruns the existing LibreOffice/PyMuPDF extraction path on demand and caches the recovered slide. PPTX slides are not text-highlighted. |
| Chat attachments | Mobile photo capture accepts JPG/PNG/WebP, resizes the image in the browser, uses the configured vision model to transcribe the problem, then sends the text through the course-grounded tutor. PDF/PPTX/video attachments upload to the course library and show a processing message; users are told to wait until the source status is Ready before asking about it. Photos are not silently stored in the course library. |
| Tutor answers | Renders Markdown, GitHub-flavored tables/lists, code fences, and KaTeX math. Raw HTML is disabled. The full-width composer has an in-bar reply-language selector for English, Hindi, Hinglish, Tamil, Telugu, Bengali, and Marathi; legacy inline sentence-number markers are cleaned up and new responses are instructed to keep citations in the source panel. Existing page motion is retained, with a restrained focus animation that respects reduced-motion settings. Starter prompts use a real Ready-source title when available, and topic prompts are limited to topics linked to Ready source units. |
| Revision and exams | Study plans and task completion persist to the signed-in account and can be selected from plan history; any still-available legacy browser plan is imported. A daily queue lists due concepts and opens adaptive practice. Mock exams count down at 90 seconds per question and auto-submit; practice/diagnostic quizzes retain an elapsed timer. |
| Exam Lab | Adds one printable, citation-linked revision page per processed course topic (definitions, source-supported formulas, examples), an auto-built plain-language glossary, and a past-paper coverage ranking with exact evidence links. The predictor analyzes all selected ready PDF/PPTX sources (no arbitrary 20-paper cap) and reports observed historical frequency—not future-exam probability. The daily goal syncs with account settings; XP/streak details remain browser-local. |
| Account, chat, and library fixes | Added an account Settings page with daily goal, reminder-time preference, language preference, accessibility controls, a combined server/browser JSON export, and account data deletion. Chat history is visible even when empty or unavailable and has loading/error/retry states. Course/source rename controls are icon-only pencil buttons; course deletion is confirmed. Unhandled API errors now log the original cause and flag a missing schema with the required setup command. |
| Tutor streaming and verification | Adds an SSE-based response path while retaining the original JSON endpoint for compatibility. The tutor streams completed sentences after a second configured model checks each one against retrieved course units; unsupported claims are withheld and the saved answer notes when that happens. Saved sentences carry hidden verification metadata rendered as source-check badges, and citations remain clickable. Model verification is a helpful check, not a guarantee of correctness. |
| Exports and overview | Generated flashcards can be downloaded as Anki-importable CSV with source locations. The Study Guide export has been removed from the course page and API; the source-linked CSV export remains. Course/source/unit/Ready/processing metrics use clearer responsive cards. |
| Existing type issues | Fixed the baseline retrieval token inference and assessment question filter typing issues, plus page-locator narrowing for citation previews. |

## Not represented as complete

The tutor reveals complete sentences only after they pass verification (rather than exposing unverified model tokens). Push reminders, a separate PDF-notes export, and shared-course permissions are not part of this update. Cheat sheets can be printed to PDF through the browser. Shared access requires a permissions model, and durable push reminders require a scheduler; avoid implying those are implemented.

XP/streak details remain browser-local and are not synchronized across devices. The selected language is a saved preference, not a full translation of the interface; reminder time is saved but push notifications are not implemented. YouTube remains subject to YouTube caption/download access rules. If a video blocks both captions and download, the source row displays the worker's error and allows retry; local deployments can configure the documented `YTDLP_COOKIES_FILE` or `YTDLP_COOKIES_BROWSER` values. Keep personal cookies and API keys out of source control. If a page shows a database schema error after updating, verify the `.env` `DATABASE_URL`, stop the dev servers, run `pnpm run setup` once, then restart `pnpm run dev`.

## Validate and run

Run `pnpm install --frozen-lockfile`, then `BASE_PATH=/ PORT=5174 pnpm run build` for a full workspace build in this repository. Use `pnpm run dev` for local development after copying `.env.example` to `.env` and configuring the required database/auth/model variables. Production source processing uses `uv sync` and the Python dependencies in `pyproject.toml` (PyMuPDF, python-pptx, yt-dlp). Keep persistent storage mounted if uploaded originals and previews must survive server restarts.
